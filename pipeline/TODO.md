## 3. 카테고리 계수 결정

지금은 카테고리가 점수에 개입하지 않는다(전부 ×1). 필요하면 `issues.mjs`에 계수를 두고
`rowMultiplier`에 곱하면 된다. 후보안:

```
재난·속보   ×1.5
인물        ×1.2
작품·콘텐츠 ×1.2
스포츠      ×1.1
기업·주식   ×1.0
사건·사고   ×1.0
정치·사회   ×0.9
```

카테고리는 `text_extractions`에 이미 쌓이므로 **API 재호출 없이 숫자만 바꿔 반영**된다.

## 5. 원문의 HTML 엔티티 정리

더쿠·유튜브 제목에 `&#039;`(작은따옴표) 같은 HTML 엔티티가 디코딩되지 않은 채 `raw_signals.text`에 저장된다.

```
A2O LITE &#039;NEON&#039; 멜론 탑백 10위
```

지금은 읽는 쪽(`issue-prompt.mjs` `decode`, 저장되는 예문)에서 풀고 있다. 같은 글이 엔티티 유무로 `text_hash`가
갈릴 수 있으니 수집 단계(`sources/*.mjs`)에서 디코딩하는 게 맞다. 과거 행은 그대로 두거나 별도 정리.

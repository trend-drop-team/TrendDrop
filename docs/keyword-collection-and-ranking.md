# 키워드 수집과 순위 계산

이 문서는 TrendDrop이 인터넷에서 키워드를 모으고 순위를 만드는 과정을 쉽게 설명한다.

## 한눈에 보는 과정

```text
인터넷 자료 수집 → 원문 저장 → 제목·댓글에서 단어 추출
→ 점수 계산 → 이상한 단어 제거·이름 보정 → 최종 키워드 10개 저장
```

## 어디에서 자료를 가져오나?

매시간 다음 5곳을 확인한다.

| 출처 | 가져오는 자료 |
|---|---|
| 디시인사이드 실시간 베스트 | 게시글 제목 |
| 더쿠 핫게시판 | 게시글 제목 |
| 인스티즈 실시간 인기 | 게시글 제목 |
| YouTube | 인기 영상 제목과 댓글 |
| Google Trends | 한국에서 급등한 검색어 |

가져온 자료는 `raw_signals` 테이블에 저장한다. 같은 출처에서 같은 제목이 같은 시간에 반복되면 한 번만 저장한다.

## 키워드는 어떻게 뽑나?

제목이나 댓글을 단어로 나눈 뒤 URL, 이모지, 특수문자, 반복 문자, 조사·어미, 숫자만 있는 값, 너무 짧은 단어, 불용어를 제거한다. 이후 LLM이 일반 단어, 문법 조각, 잘못 잘린 이름을 걸러내고 필요한 경우 이름을 복원하거나 같은 대상을 합친다.

## 기존 순위와 새 점수

기존 순위는 “최근 6시간 동안 얼마나 많이, 중요한 곳에서 언급됐나?”를 계산한다. 새 급상승 점수는 “최근 1시간에 갑자기 더 많이 언급됐나?”를 계산한다.

| 구분 | 기존 인기 점수 | 새 급상승 점수 |
|---|---|---|
| 보는 것 | 최근 6시간의 전체 인기 | 최근 1시간의 증가세 |
| 비교 대상 | 다른 키워드 | 같은 키워드의 이전 시간대 |
| 주요 입력 | 출처 가중치, 조회수, 좋아요, 언급 수 | 최근 1시간 언급 수, 이전 시간대 평균 |
| 의미 | 지금 가장 많이 언급되는 키워드 | 방금 빠르게 떠오르는 키워드 |
| DB 컬럼 | `score` | `rising_score` |

기존 `score`로 정하는 `rank`는 그대로 유지한다. 프론트에서는 각 키워드 아래에 `인기 점수`와 `급상승 점수`를 텍스트로 함께 보여주고, `rising_score`가 85점 이상이면 키워드 왼쪽에 `급상승` 배지를 표시한다.

## 기존 인기 점수 계산

| 자료 | 기본 가중치 |
|---|---:|
| Google Trends 검색어 | 20 |
| YouTube 영상 제목 | 12 |
| 커뮤니티 게시글 제목 | 4 |
| YouTube 댓글 | 3 |

YouTube는 조회수·좋아요·댓글 수가 많으면 추가 점수를 받고, Google Trends는 검색량이 높을수록 추가 점수를 받는다. 같은 키워드가 여러 출처에서 발견되면 보너스도 받는다.

```text
인기 점수 = 출처 가중치 × 반응 보정 × 여러 출처 보너스
```

## 급상승 점수 계산

기본 6시간 창에서 최근 1시간과 직전 5시간을 비교한다.

예를 들어 `카카오`가 직전 5시간에 10회, 최근 1시간에 6회 언급됐다고 하자.

```text
이전 시간당 평균 = 10회 ÷ 5시간 = 2회
최근 언급량 = 6회
급상승 점수 = (6회 ÷ (2회 + 1)) × 50 = 100점
```

점수는 0~100 사이로 제한한다. 이전 데이터가 없거나 수집이 빠진 시간대가 있으면 실제로 존재하는 시간만 사용하고, 계산 오류를 막기 위해 분모는 최소 1로 처리한다.

## DB에 저장되는 값

| 테이블 | 설명 |
|---|---|
| `raw_signals` | 인터넷에서 가져온 원문 |
| `keyword_verdicts` | LLM의 키워드 인정·제외 기록 |
| `keywords` | 최종 채택된 키워드 목록 |
| `trend_snapshots` | 실행 시점별 순위와 점수 |
| `collection_runs` | 수집·순위 계산 실행 기록 |

`trend_snapshots`에는 다음처럼 저장된다.

```text
score: 32              // 최근 6시간 인기 점수
mentions: 16           // 최근 6시간 전체 언급 수
rising_score: 100      // 최근 증가세 점수
baseline_mentions: 10 // 이전 시간대 언급 수
rank: 5                // 인기 점수 기준 순위
```

지금은 `score`로 기본 순위를 보고, `rising_score`가 높은 키워드를 별도로 보면 된다.
